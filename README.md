# Life

Private routines and finances. Data stays in your browser.

## Run it

```bash
npm install
npm run dev
```

Open the URL on your computer, or on your iPhone on the same Wi-Fi.

## Put it on your iPhone Home Screen

Safari only allows “Add to Home Screen” over **https** (or localhost). Easiest path:

1. Deploy the `dist` folder to any static host (Vercel, Netlify, GitHub Pages).
2. On the iPhone, open the site in **Safari**.
3. Share → **Add to Home Screen**.

It opens full-screen like an app. Completions, transactions, and your weekly plan are stored on the device. Export a backup from **Today → ⚙️** if you switch phones.
